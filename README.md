# FakerAPI API Automation Testing

API automation testing framework using Java, RestAssured, TestNG, Maven, and MVC (Model View Controller) pattern.

## Tech Stack

* Java 17
* Maven 3.9+
* RestAssured
* TestNG
* MVC Pattern

---

# Prerequisites

Install the following tools:

* Java JDK 17
* Maven
* IntelliJ IDEA or Eclipse

---

# Installation

## 1. Verify Java

```bash
java -version
```

---

## 2. Verify Maven

```bash
mvn -version
```

---

# Clone Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

---

# Open Project

Open the project using:

* IntelliJ IDEA
* Eclipse

Import as:

```text
Maven Project
```

---

# Install Project Dependencies

Run:

```bash
mvn clean install
```

Maven will automatically download all required dependencies.

---

# Run Automation

Run automation test using:

```bash
mvn clean test
```

or run directly:

```text
PersonAPITest.java
```

from IDE.

---

# Notes

* Test result and API response will be displayed in console.
